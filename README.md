One line, at most 200 characters: the funniest honest error message an
appliance could show. Our washing machine, deadpan, after six detergent-free
cycles: "ERROR: Detergent drawer empty. I have run 6 cycles on hope and tap
water. Hope is not a cleaning agent."

The line was chosen by duel-testing 8 original drafts pairwise in both
orders (see DUEL.md); it went 7–0. The fault is real, the joke comes from
the fault itself, and the machine's voice stays flat throughout.

## Run it

```sh
python3 main.py
```

It prints exactly one line to stdout and also writes it to
`/output/entry.txt` for the sealed scorer.
